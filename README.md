# Automatic Room Light and Fan Controller

## Project Overview

This project is designed to automatically control room lights and fans based on the presence of people in the room.

The system helps reduce unnecessary electricity consumption and provides automatic control of electrical appliances.

## Objectives

- Automatically detect people entering and leaving a room.
- Turn ON the light when a person enters.
- Turn OFF the light when the room becomes empty.
- Control the fan automatically.
- Reduce unnecessary power consumption.

## Components Used

- Arduino UNO
- IR Sensor / PIR Sensor
- Relay Module
- Light
- Fan
- Connecting Wires
- Breadboard
- Power Supply

## Working Principle

1. The sensor detects a person.
2. The sensor sends a signal to the Arduino.
3. Arduino processes the signal.
4. The relay switches the light and fan ON.
5. When the room becomes empty, the relay switches the appliances OFF.
